# 2026-08-29

- 휠 엔코더 도착: Omron E6B2-CWZ6C, 360P/R, incremental quadrature,
  NPN open-collector 출력, 전원 5~24VDC. (2026-08-10 devlog에서 검토했던
  타이어 사이드월 마찰 롤러 장착 방식 그대로 진행.)
  출력이 NPN open-collector라 배선 계획을 세울 때 걱정했던 5V→3.3V
  레벨시프터는 필요 없음 — 풀업 전압을 3.3V로 걸면 그대로 ESP32 GPIO에
  물릴 수 있음 (Omron 공식 데이터시트 확인: 인가전압 30VDC까지, sink
  35mA까지 허용).
- `E,<ltick>,<rtick>\n` 프로토콜을 펌웨어/base_driver.py 양쪽에 구현:
  - `esp32_joystick_emulator.ino`: GPIO15/16=좌측 A/B, GPIO17/18=우측 A/B.
    Brown(+Vcc)=5V, Blue(0V)=GND, Orange(Z상)=미배선(사용 안 함). PCNT
    하드웨어 대신 CHANGE 인터럽트 + 상태 전이표로 x4 quadrature 디코딩
    구현 (arduino-esp32 코어 버전 의존성 없이 동작, 이 정도 펄스 속도엔
    충분). 20ms 주기로 `E,<ltick>,<rtick>\n` 시리얼 송신.
    ★ 배선 시 A/B 각 선마다 3.3V로 풀업 저항(4.7kΩ 권장) 추가 필수 ★
    (GPIO `INPUT_PULLUP`도 걸어두지만 백업용, 외부 풀업이 메인).
  - `base_driver.py`: 별도 스레드에서 시리얼 read (`control_loop`는 계속
    메인 스레드에서 write), `E,` 라인 파싱해서 `/wheel/ticks`
    (`Int32MultiArray`, `[left, right]`)로 발행 + 2초 주기로 좌우 tick/차이
    로그 출력.
  - 아직 안 한 것: 롤러/타이어 지름비 실측(틱→거리 환산 불가), open-loop
    오도메트리를 실측 틱 기반으로 교체, `STEERING_TRIM_COUNTS` 자동 계산.
    이번 작업은 프로토콜 구현까지만 — 다음 단계는 실차에 엔코더 장착 후
    직진 주행 테스트로 좌우 tick 차이를 실측하는 것.
  - `arduino-cli compile --fqbn esp32:esp32:esp32s3`, `colcon build
    --packages-select autonomous_wheelchair` 둘 다 통과 확인. 아직 실제
    하드웨어에 장착/업로드는 안 함.
